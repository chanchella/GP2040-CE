# OAG DIAMOND RS8 • F1 KM FIX2 • Pico 2 W

إصلاح فقد الماوس والكيبورد عند اختيار لعبة بـF1 + رقم، فوق نسخة Pro Input / F1 Context Fix. النسخة الأساسية RS8 V2 والنسخة Golden لم تتغيرا.

## التغيير

اختيار اللعبة عاد إلى RAM فقط، مثل RS8 V2 التي كانت تعمل. أُزيل حفظ Flash أثناء الاختصار، وأُزيل تعطيل خرج الماوس والكيبورد وتصفير الحركة المنتظرة وبواقي الكسور. لا يغيّر الاختصار نوع الخرج أو اتصالات USB/Bluetooth. تُلغى تأثيرات اللعبة السابقة، ويُعاد إرسال الحالة الحالية للمدخلات.

- **F1 + رقم 1..20 لمدة ثانية:** اختيار اللعبة، مع استمرار الماوس والكيبورد والدراع في وضع الخرج الحالي.
- **F1 + 0 لمدة ثانية:** إلغاء اختيار اللعبة وتأثيراتها، مع استمرار المدخلات وDPI والحساسية وبواقي الكسور ووضع الخرج الحالي.
- **F5 + رقم 1..24 لمدة ثانية:** اختيار سلاح اللعبة النشطة. بعد F1 + 0 لا يُفعّل سلاح حتى تختار لعبة.
- رقم من خانتين: أمسك F1 أو F5، أدخل الخانتين بالترتيب، وانتظر ثانية بعد آخر خانة.
- الاختصارات تغير الجلسة فقط؛ الحفظ الدائم يظل من صفحة الإعدادات. عند إعادة التشغيل يُستخدم اختيار بدء التشغيل المحفوظ.

## التركيب والتحقق

انقل ملف UF2 الجديد في وضع BOOTSEL. لا تمسح Flash أو تستخدم flash_nuke للحفاظ على الألعاب والإعدادات والموديلات المحفوظة.

اختبار جديد يستدعي كود الاختصار الفعلي من main.cpp، ويختبر الألعاب العشرين ثم الإلغاء، مع زر W مضغوط وحركة ماوس منتظرة أثناء انشغال منفذ الخرج وبواقي كسور غير صفرية. فشل قبل الإصلاح بسبب حفظ Flash، واجتاز بعده. اجتازت جميع اختبارات C++ الـ25 وحارس المعمارية وقوائم RS8 العربية.

هذه نسخة مرشحة لتجربة الإصلاح على الجهاز؛ الاختبارات البرمجية لا تعني تحققًا فعليًا على Pico 2 W. صفحة Wi-Fi أثناء اللعب وتشغيل Wi-Fi وBluetooth بالتزامن لم يُضافا في هذا الإصلاح.
